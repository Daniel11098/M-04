# KI-avtale – Mobil Programmering
---

## 1. Hva bruker vi KI til?

- Repetisjon av grunnleggende konsepter som vi lærte i timen
- Forklaring av ulike konsepter
- Forklaring med eksempler
- Feilsøking, altså hvis vi får feil melding så kan vi feil søke det med KI
- Forslag til andre muligheter enn det vi har i koden for, men da må vi gjøre følgende:
  1. Se om det passer i arkitekturen
  2. Se om vi faktisk forstår de andre mulighetene
  3. Kunne begrunne hvorfor det er bedre enn det vi allerede har
- Styling
  1. KI kan gjøre livet vårt lettere med å style ulike komponenter for oss, på den måten vi ønsker, men det skal bli brukt bevist på hva den faktisk produseres og da må vi forstå hvordan den Stylesheet er bygget opp og hva de ulike verdiene inni innebærer og betyr.

## 2. Hva gjør vi selv?

- Planlegger komponenter ved å enten tegne eller bruke verktøy som «excalidraw»
- Skissere arkitekturen selv
- Skrive koden selv
- Feilsøking og fiksing av koden selv, (med hensyn på at vi kan bruke KI for å forstå feil meldingene)
- Lære grunnleggende konsepter fra timen og bruke de selv FØR vi spør KI om dem, for hvis vi ikke feiler så lærer vi ingenting.
- Prøve selv minst 5 ganger før vi bruker KI når vi sitter fast
- Begrunne ulike valg selv

## 3. Hvordan vet vi at svaret er riktig?

- Sammenligne det vi får ut av KI/Det vi sliter med, med koden fra timen
- Spørre foreleser (favoritten min)
- Spørre studentassistene
- Teste koden med consol.log () for å se hvor er det koden vår feiler eller for å markere
- Sjekke dokumentasjon
- Se på youtube videor (favoritten min)
- Lese ulike artikler som er relevante for det vi sliter med i gruppe
